# The games

One file per game. Read the one you are touching; there is no need to read the rest.

Each covers what the game is, how a run ends, how it gets harder, how a player claws a run
back, and which constants to reach for when it feels wrong.

| Game | Genre | Record | Comeback |
|---|---|---|---|
| [Block Fit](block-fit.md) | Block puzzle | High score | Earned tray swap |
| [Merge Tiles](merge-tiles.md) | Sliding merge | High score | Undo, one earned per new biggest tile |
| [Stack Tower](stack-tower.md) | Timing | Tallest tower | Width won back by a perfect drop |
| [Tile Tap](tile-tap.md) | Rhythm/reflex | Tiles hit | Earned skip |
| [Star Catcher](star-catcher.md) | Reflex | Stars caught | Heart pickup |
| [Sliding Puzzle](sliding-puzzle.md) | Thinking | Fewest moves | None; no clock pressure |
| [Odd One Out](odd-one-out.md) | Perception | Furthest level | A life back every five levels |
| [Colour Sequence](colour-sequence.md) | Memory | Rounds repeated | One forgiven slip |
| [Unicorn Tap](unicorn-tap.md) | Demo | None | None |

Every game meets the bar in `../game-engagement.md`. Anything new has to as well.
